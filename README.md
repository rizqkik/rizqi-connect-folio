# Rizqi Fauzan Portfolio

Create a modern personal portfolio landing page for Muhammad Rizqi Fauzan, a fresh graduate in Telecommunication Engineering from Politeknik Elektronika Negeri Surabaya (PENS).

The website should feel like a real engineer's personal portfolio, not an AI-generated template. The visual direction should be clean, mature, technical, minimal, and highly intentional.

DESIGN DIRECTION

Avoid the typical "AI portfolio" aesthetic:

No excessive purple/blue gradients

No glowing neon effects everywhere

No excessive glassmorphism

No floating blobs

No overuse of rounded cards

No futuristic sci-fi interface

No excessive animated elements

No generic "AI Engineer" landing page appearance

Instead, create a design inspired by modern engineering portfolios, premium developer websites, editorial layouts, and technical documentation websites.

The page should feel:

Professional

Technical

Calm

Intelligent

Minimal

Human

Slightly experimental

Premium but not corporate

Use generous whitespace and strong typography hierarchy.

TYPOGRAPHY

Typography is extremely important.

Use a modern, highly readable sans-serif font such as:

Inter

Geist

Manrope

Plus Jakarta Sans

Prefer Geist or Inter for the primary UI.

Do NOT use futuristic display fonts.

Use typography with clear hierarchy:

Large but restrained hero heading

Medium-weight section headings

Normal-weight body text

Small uppercase labels for metadata

Avoid excessively bold text everywhere.

COLOR SYSTEM

Use a mostly neutral palette.

Primary:

Off-white / warm white background

Near-black text

Dark gray secondary text

Subtle gray borders

Use one restrained accent color inspired by engineering/technology, such as muted blue or deep teal.

The accent should be used sparingly for:

Links

Small indicators

Buttons

Hover states

Active navigation

Do not turn the entire interface blue.

The final result must NOT look like it was generated from a generic AI website prompt.

"engineering portfolio + editorial design + modern developer website"

rather than:
"AI startup landing page".

Prioritize:

Typography

Spacing

Information hierarchy

Layout

Subtle interaction

Content clarity

Use real content from the provided CV rather than inventing achievements, companies, technologies, or statistics.

Build the page as a polished production-ready portfolio with clean reusable components and consistent spacing throughout.
